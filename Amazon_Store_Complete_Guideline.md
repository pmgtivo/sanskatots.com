## PART 3 — BRAND IDENTITY SYSTEM FOR AMAZON STORE

Use these tokens consistently across EVERY tile, banner, and image in your store. Inconsistency signals an amateur brand. Consistency signals premium.

### Color Palette

| Role | Color Name | Hex Code | Use |
|------|-----------|----------|-----|
| Primary | Saffron | `#F4A340` | CTAs, headers, highlighted text, borders |
| Secondary | Maroon | `#8C2A2A` | Section backgrounds, accent tiles |
| Accent | Teal | `#2BA8A0` | Icon accents, secondary buttons |
| Base | Cream | `#FFF8EC` | Page backgrounds, card fills |
| Dark | Charcoal | `#2A2A2A` | Body text, headings |
| Cultural (Kannada Book only) | Deep Violet | `#4A1A8C` | Kannada product tiles only |
| White | Pure White | `#FFFFFF` | Product tiles, clean sections |

### Typography

| Use | Font | Weight | Notes |
|-----|------|--------|-------|
| Headlines | Poppins or Nunito | 700–800 | Bold, rounded — child-friendly yet premium |
| Body text | Poppins or Open Sans | 400–500 | Highly readable at small sizes |
| Product names | Poppins | 600 | Medium-bold |
| Price callouts | Poppins | 800 | Extra bold |
| Kannada script | Noto Sans Kannada | 400 | Bilingual tiles |
| Hindi script | Noto Sans Devanagari | 400 | Shlokas/Gita tiles |

> Amazon Store Builder uses its own font rendering, but your uploaded **images** must follow the above. Design every graphic tile in Canva or Figma using these fonts before uploading.

### Logo Usage
- Use the SanskaTots™ logo on every banner image, bottom-right corner (8% of image width)
- Minimum clear space: equal to the height of the "S" in SanskaTots around the logo
- Never place logo on a busy patterned background — always on white, cream, or saffron
- Tagline *"Wisdom Begins Early"* appears below logo in all branding tiles

## PART 8 — STORE LAUNCH SEQUENCE (Step-by-Step)

### Step 1 — Access Store Builder
1. Login to Seller Central → Click `Stores` in the top menu
2. Click `Manage Stores` → `Create Store`
3. Select your brand: `SanskaTots` (your Brand Registry brand)
4. Choose template: **Blank** (gives you full design control — do NOT use preset templates)

### Step 2 — Configure Store Header
1. Upload brand logo (400×400px PNG, transparent background)
2. Set store tagline: `Wisdom Begins Early`
3. Upload hero banner (3000×600px)
4. Set meta title and description (from Part 5 above)

### Step 3 — Build Navigation
1. Add pages in this order: Home, Busy Books, Cultural Books, Bundles, About Us
2. Name each page exactly as above
3. Set `Home` as the default landing page

### Step 4 — Build Each Page
Build pages in this order:
1. Home page (most important — build this first, get it right)
2. Busy Books page
3. Cultural Books page
4. About SanskaTots page
5. Bundles page (depends on Virtual Bundle ASINs being created)

For each page, use the following Amazon Store module types:

| Module | When to Use |
|--------|-------------|
| `Full-width image or video` | Hero banners, brand statements |
| `Image tile with text overlay` | Brand pillar tiles, feature callouts |
| `Product grid` | Showing 3-4 products in a row |
| `Featured product` | Highlighting the flagship book |
| `Text` | Brand story sections, short body copy |
| `Video` | Brand/product reel |
| `Image + product links` | Bundle tiles linking to actual ASINs |

### Step 5 — Link Products to Tiles
- Every product tile must be linked to its ASIN product page
- Do NOT link to external URLs — Amazon will reject them
- Use the ASIN search in the Store Builder to find and link each product

### Step 6 — Mobile Preview
- After building each page, click `Preview` → Switch to mobile view
- Check all text is legible
- Check no content is cut off at edges
- Check CTA buttons are tappable (min 44×44px touch target)

### Step 7 — Submit for Review
- Click `Submit for Publishing`
- Amazon review time: typically 24–72 hours
- You will receive an email when approved
- Store URL will be: `https://www.amazon.in/stores/SanskaTots`

### Step 8 — Post-Launch
- Share the store URL in your Instagram bio (@sanska_tots)
- Use the Amazon Posts feature (Stores → Posts) to share content from your store
- Set up Amazon Brand Analytics to monitor store traffic and performance

## PART 10 — AMAZON POSTS STRATEGY (Free Brand Content)

Amazon Posts is a FREE social-media-style feed linked to your Brand Store. Every post drives traffic to your store and product listings.

**Access:** Seller Central → Brands → Posts → Create Post

**Recommended posting frequency:** 3–5 posts per week after launch

**Content pillars for Posts:**

| Pillar | Post Type | Example |
|--------|-----------|---------|
| Product demo | Short video or 3-image carousel | Write-wipe-repeat demo of Montessori Busy Book |
| Educational | Infographic or tip image | "5 signs your child is ready for school" |
| Lifestyle | Indian family using books | Parent reading Shlokas book with toddler at bedtime |
| Cultural | Festival tie-ins | "The perfect Diwali gift for your little one" |
| Product spotlight | Single product highlight | "8 animal worlds in one book — Animals Busy Book" |
| Review/social proof | Screenshot of a parent review | Real 5-star review made into a graphic |

**Post specifications:**
- Image: 1:1 square (1080×1080px) or 4:5 portrait
- No pricing in posts (Amazon policy)
- Brand logo on every post image
- All text must be clearly readable on mobile
